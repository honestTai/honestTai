## HRouter 与这些项目的关系

[HRouter](https://hrouter.net/home) 是由本账号运营者提供的 AI 模型路由服务，提供统一密钥与模型接入入口。如果你需要为 AI 工具配置模型服务，可以先查看网站的使用帮助、可用模型和计费说明，再决定是否使用。

- **HRouter Desktop** 是面向 HRouter 的客户端，使用时需要 HRouter Key。
- **其他项目不因列在这里就必须购买 HRouter。** 模型供应商、兼容协议和配置要求以各仓库说明为准。
- **Seedance Movie MCP** 当前文档要求火山方舟 API Key；此处不宣称 HRouter 支持该视频接口。
- 开源代码的使用条件以各项目许可证为准；模型/API、服务器等服务可能另行产生费用。
- 不在 README 中承诺固定模型、价格、可用率或效果，服务信息以 HRouter 网站为准。

**先找到有用的工具，再按需选择模型服务。** 欢迎通过对应仓库的 Issues 提交不含敏感信息的反馈；如果项目对你有帮助，也欢迎点一个 Star。

> 不要在 Issue、PR、截图或日志中公开 API Key、客户数据和账号凭据。HRouter 与上游模型厂商的官方身份无关，本页不代表上游厂商背书。
