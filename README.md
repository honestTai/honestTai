## HRouter · AI 模型接入服务 / AI model routing

**一个密钥，连接多个 AI 模型。** HRouter 面向 AI 编程与应用开发，提供模型接入、API 密钥管理、用量查询与客户端配置入口，让你把更多精力放在项目本身。

**One key, multiple AI models.** HRouter brings model access, API key management, usage tracking, and client configuration together for AI coding and application development—so you can focus on what you're building.
